# DDP PRO landing (минималистичный, премиальный редизайн)

## Что сделано
- Чистая главная с одним основным путём: **вход в B2B / каталог**.
- Без визуального шума: убраны лишние блоки и дублирующие CTA.
- Премиальная шапка: только нужные пункты + «Обратный звонок».
- Hero: H1 + преимущества, справа один компактный CTA-блок.
- «Как стать партнёром» со структурой шагов и CTA **«Первая отгрузка»**.
- Один баннер на всю ширину, ведущий в B2B.
- Новости (3 карточки) — все ведут в B2B.
- Футер с жёсткой иерархией и финальной строкой ©.
- Ненавязчивая анимация (GSAP) и hover-микроинтеракции.

## Запуск
Откройте `index.html` в браузере.

## Важно
Ссылки на B2B сейчас стоят как `/b2b` (и `/vacancies`). При необходимости замените на реальные URL вашей системы.
